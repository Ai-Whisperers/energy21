## What the project is

N8N automation of your existing CI/CD quality feedback loop. The build process already produces reports (documentation gaps, unit tests, CRAP score, license issues, warnings). Today you run prompts manually. This project implements that cycle in N8N: build report → run prompt → make fix → commit → compile → new report → repeat—automatically.

**Deliverables:** N8N workflows connecting build output to your existing prompts, automated fix-and-commit cycle, every git repository correctly documented, unit tested, and quality-compliant without manual intervention.
